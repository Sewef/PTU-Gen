📋 Overview

The PTU Pokémon Generator API provides endpoints for generating Pokémon with customized stats following the PTU 1.05 ruleset. All endpoints return JSON responses and support multiple datasets (Core, Community, Homebrew).

Base URL: /api/pokemon
Authentication: Not required - API is open to all
Response Format: All responses are in JSON format

🎲 Generation Endpoints

GET /generate

Generate a Single Pokémon

Generate a random Pokémon with customizable level, distribution method, and other parameters. This is the most flexible endpoint for creating individual Pokémon.

Query Parameters:
Parameter Type Description Example
level number Specific level (1-100). Use this OR minLevel/maxLevel level=50
minLevel number Minimum level for random range minLevel=30
maxLevel number Maximum level for random range maxLevel=60
species string Specific Pokémon species name (e.g., 'Pikachu'). If omitted, random species is chosen species=Charizard
habitat string Restrict species to a specific habitat. Random species from that habitat is chosen habitat=Cave
shiny boolean Force the Pokémon to be shiny shiny=true
shinyOdds number Custom shiny odds (default: 1/8192). Must be between 1/1 and 1/1000000 shinyOdds=0.001
distribution string Stat distribution method: RANDOM, BALANCED, or MINMAXED (default: RANDOM) distribution=MINMAXED
ignoreBaseRelation string Disable Base Relation for specific stats. Use 'IGNORE' for all or comma-separated list (HP,ATK,DEF,SPA,SPD,SPE) ignoreBaseRelation=ATK,SPA
hpFormula string Custom HP calculation formula using 'LEVEL' and 'HP' placeholders hpFormula=LEVEL+(HP*2)
dataset string Data source: core, community, or homebrew (default: core) dataset=community
nature string Specific nature (e.g., 'Adamant', 'Timid'). If omitted, random nature is chosen nature=Adamant
includeLegendaries boolean Include legendary Pokémon in generation (default: false - legendaries are excluded) includeLegendaries=true

GET /api/pokemon/generate?species=Dragonite&level=75&distribution=MINMAXED&nature=Adamant&shiny=true

⚙️ Query Parameters Guide

Distribution Methods

The distribution method determines how stat points are allocated:

RANDOM: Points are distributed randomly across stat groups (default method).
BALANCED: Equal points are distributed to all stat groups, resulting in more evenly distributed stats.
MINMAXED: Stat points are weighted by base stats. Stats with higher base values receive more points, while lower base stats receive fewer points. Results in more specialized Pokémon.

Base Relation System

Base Relation groups stats that share the same base value together. Stats in the same group always receive the same point allocation. Use ignoreBaseRelation to disable this behavior.

IGNORE: Completely disables Base Relation for all stats. Each stat is distributed independently.
Comma-separated list: Disable Base Relation only for specified stats. Example: ignoreBaseRelation=ATK,SPA Other stats still maintain their Base Relation groupings.
Stat Abbreviations: HP, ATK, DEF, SPA (Special Attack), SPD (Special Defense), SPE (Speed)

HP Formula

Customize how HP is calculated for generated Pokémon. Use placeholders:

LEVEL: The Pokémon's level
HP: The assigned HP stat value
Default formula: LEVEL + (HP * 3) + 10
Example custom formulas:
LEVEL + (HP * 2) // Halved HP gain
LEVEL + (HP * 4) // Increased HP gain
(HP * 2) + 50 // No level scaling

Legendary Pokémon

Control whether legendary Pokémon can be generated using the includeLegendaries parameter.

Default behavior: Legendary Pokémon are excluded by default (includeLegendaries=false). This ensures generated teams consist of non-legendary species.
To include legendaries: Set includeLegendaries=true in your request. This allows legendary Pokémon like Dragonite, Ho-Oh, Dialga, etc. to be generated.
Note: The includeLegendaries parameter only applies when generating random species. If you specify a legendary species directly with the species parameter, it will always be generated regardless of this setting.

Error Responses

Common error responses:

Invalid level:
{ "error": "Level must be between 1 and 100" }
Invalid species:
{ "error": "Species not found in dataset: InvalidPokemon" }
Invalid habitat:
{ "error": "No Pokemon found in habitat: InvalidHabitat" }
